# 验证与模型适用范围

原数值基线为 61 项单元／接口测试、24 组案例配置复算，并完成过独立目录命令和测试运行。环境为 Python 3.10.11、NumPy 1.26.4、SciPy 1.14.1；图表使用 Matplotlib 3.7.1。历史基线及当时的源码哈希见[data/validation_snapshot.json](data/validation_snapshot.json)。

2026-10-27 的图表更新另外增加了分离孔洞与采样凸包遮罩、低载窄接触区、斜齿压力范围、原数组不变性、瞬时压力积分恢复单齿对载荷、原条带半宽及峰值复现、零载与相位选择检查，当前共 **67 项测试**。本次只改变展示与仓库文档，未修改力学计算内核；README 三组对比和独立的对中鼓形瞬时斑点案例使用 64 相位、41 条带重新求解，完整数据保存在 `output/readme_examples/`。

验证覆盖解析弹簧、单边开闭、零载荷右切线、随机正定柔度的接触子集穷举、非线性切线、Hertz积分及压陷导数、梁解析解、弹性互易、几何与材料相似律、内外啮合、螺旋手性、配置重算、频谱及图表数据对应。

24组案例的最大力残差约9.095e−13N，最大接触间隙残差约1.998e−12m；这些是所解离散方程的残差，不是实物误差。

组合修形案例21→41条带的变化：TE约0.1274%、峰值压力约0.02379%、平均切线刚度约0.8189%。32→64相位的变化：TE约0.2673%、压力约0%、平均刚度约0.1272%。这些检查只覆盖该案例、该模型及所列指标，不给出全参数域误差界或收敛阶。

## 本地复核

```bash
python -B -m unittest discover -s tests -v
python -B scripts/check_project.py
python -B examples/run_examples.py --output output/full
python -B examples/check_phase_resolution.py --output output/phase_resolution
```

GitHub Actions配置是后续复核入口，远端CI结果以上传后的实际运行记录为准。本地运行记录默认写入被忽略的`output/project_check.json`。
